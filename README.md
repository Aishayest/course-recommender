# Course Recommender

Рекомендательная система выбора университетских курсов: подсказывает, что брать
в следующем семестре, с учётом требований handbook и реального шанса попасть на курс.

## Идея

Handbook описывает, что студент обязан пройти, но на регистрации приоритет
достаётся не всем. Система совмещает три слоя:

1. **Ограничения** — пререквизиты, кредиты, квоты категорий. Детерминированные
   правила, не ML: модель не должна предлагать невалидное.
2. **Релевантность** — content-based эмбеддинги описаний курсов плюс профиль
   студента, собранный из пройденных курсов с весом по оценкам.
3. **Доступность** — вероятность получить место, обученная на истории регистраций.

Итог — не топ-5 по релевантности, а портфель с запасными вариантами:
«бери A, но если не дадут — B закрывает то же требование».

## Структура

```
src/course_recommender/
├── domain.py              доменная модель: курсы, студенты, требования
├── constraints.py         жёсткие правила handbook
├── recommend.py           сборка пайплайна и функция полезности
├── data/
│   ├── canva.py           извлечение handbook из Canva
│   ├── handbook.py        учебные планы по семестрам
│   ├── requirements.py    требования по категориям
│   ├── registration.py    пререквизиты и тиры приоритета регистрации
│   ├── assemble.py        сборка Program: каталог + требования
│   ├── catalog.py         каталог курсов университета (заглушка)
│   └── transcripts.py     истории регистраций (заглушка)
└── models/                эмбеддинги, доступность мест, ранжирование
```

## Данные

Handbook выгружается из Canva по годам поступления:

```bash
uv run python -m course_recommender.data.canva --all
uv run python -m course_recommender.data.assemble --year 2026 --program "COMPUTER SCIENCE"
```

Пререквизиты и приоритеты — из документа Registrar, который публикуется перед
каждой регистрацией:

```bash
uv run python -m course_recommender.data.registration "Course Requirements ... Fall 2026.pdf" \
  -o data/raw/requirements_fall2026.json
```

## Установка

```bash
uv sync --extra dev
uv run pytest
```

Эмбеддинги тянут torch, поэтому вынесены отдельно:

```bash
uv sync --extra embeddings
```

## Статус

Разобран handbook за 2023-2026: 79 из 80 связок "год поступления + специальность"
покрыты учебным планом или таблицей требований. Из них собираются Program с
каталогом курсов, требованиями по категориям и минимальными оценками, поверх
которых работает слой ограничений.

Не хватает двух источников:

- **описания курсов** для content-based эмбеддингов — handbook и документ
  Registrar дают только названия.
- **снимки заполняемости во время регистрации** — расписание с `Enr`/`Cap`
  показывает состояние до и после, но не скорость, с которой разбирают места.
